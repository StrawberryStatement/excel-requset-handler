# 测试计划

本文档约束 V2 后续实现的测试范围。

## 1. Excel 读取测试

需要覆盖：

1. 能读取中文表头。
2. 能忽略空行。
3. 能发现重复表头。
4. 能发现缺少云服务列。
5. 能识别云服务为空。
6. 能保留原始行数据。

## 2. FE / RR 关联测试

需要覆盖：

1. FE 和 RR 都存在，正常按 FE 合并。
2. RR 存在、FE 为空，且能通过 RR 找到唯一 FE，标记 `FE候选`。
3. RR 存在、FE 为空，且找不到 FE，标记 `待建FE`。
4. FE 存在、RR 为空，标记 `无外部RR`。
5. FE 和 RR 都为空，标记 `缺主键`。
6. 一个 RR 对多个 FE，标记 `RR拆分`。
7. 多个 RR 对一个 FE，标记 `RR合并`。
8. 同一个 RR 在不同来源列表中对应不同 FE，标记 `RR拆分待确认` 或 `RR关联异常`。
9. 同一个 FE 在不同来源列表中对应不同云服务，标记 `云服务冲突`。
10. 同一个 FE 出现在多个来源列表中，标记 `多来源共同管理`，并作为高优先级异常。

## 3. 云服务维度测试

需要覆盖：

1. 来源列表包含 A、B、C、D 多个云服务。
2. 页面配置“我负责的云服务”为 A、B。
3. A、B 被标记为归我负责。
4. C、D 被标记为非我负责。
5. 可以按云服务筛选。
6. 可以按是否归我负责筛选。

## 4. 空值填充规则测试

需要覆盖：

1. 云服务列存在但单元格为空时，可以按规则填充。
2. 其他字段为空时，也可以按规则填充。
3. 缺少云服务列时，默认判定为问题。
4. 用户显式选择“创建虚拟列并填默认值”后，可以生成标准化云服务值。
5. 原始行数据保留填充前状态。
6. 异常项记录填充动作。

## 5. 来源列表类型测试

需要覆盖：

1. 上传文件默认以文件名作为专项名称。
2. 第一版来源列表类型可以统一为 `需求列表`。
3. 来源列表名称进入在线预览和导出结果。

## 6. 待回刷评论测试

需要覆盖：

1. 页面可以选择进入评论的字段。
2. 未选择字段不进入评论。
3. 多个来源列表对同一个 FE 的扩展信息并排展示。
4. 评论按来源列表分块生成。
5. 严重异常默认不进入待回刷评论。
6. 评论目标支持 `FE`、`RR`、`FE+RR`。
7. `待建FE` 在没有 FE 编号时只能生成 RR 侧评论候选。
8. 默认只给当前 FE 或 RR 生成评论。
9. 勾选“同步评论到一层关联对象”后，同时给直接关联的 FE/RR 生成评论。
10. 同步评论不能递归扩散到二级关联对象。
11. 状态变化也以评论形式进入待回刷，不做结构化状态更新。
12. 评论格式符合固定模板。
13. 缺失字段不输出空行。
14. 支持默认评论模板。
15. 支持新增、编辑、删除、保存评论模板。
16. 支持从字段名识别对齐时间和对齐对象。
17. 支持从内容关键字识别对齐时间和对齐对象。
18. 评论模板第一版保存在浏览器 localStorage。
19. 支持预留模型识别接口。

## 7. 待建 FE 闭环测试

需要覆盖：

1. `待建FE` 单独进入导出 sheet。
2. 支持导入 RR-FE 映射表。
3. 使用 `RR编号 + 云服务` 匹配待建记录。
4. 支持 `FE编号 + RR编号`、`FE编号 + 云服务` 作为辅助匹配。
5. 回填后状态从 `待建FE` 变为 `FE已补齐`。
6. 回填后记录进入 FE 视角。

## 8. 在线预览测试

需要覆盖：

1. API 返回摘要卡片数据。
2. API 返回 FE 视角预览行。
3. API 返回 RR 视角预览行。
4. API 返回异常列表。
5. 支持按云服务筛选。
6. 支持按来源列表类型筛选。
7. 支持按异常状态筛选。
8. 支持搜索 FE、RR、需求标题。
9. 多来源共同管理行有高亮标记。

## 9. 导出测试

需要覆盖：

1. 只暴露一个主下载：`需求汇总包.xlsx`。
2. 汇总包包含必需 sheet。
3. `待建FE` sheet 存在。
4. `原始行数据` sheet 保留来源文件、行号和原始字段。
5. `待回刷评论` sheet 只包含用户选择的字段。
6. `异常项` sheet 包含异常级别和处理建议。
